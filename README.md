# telemetry_tool

Утиліта мовою Python для зчитування, синтаксичного розбору, аналізу та
відмовостійкого збереження телеметрії апаратних сенсорів комп'ютерної
мережі моніторингу (Варіант 1).

## Можливості

- потоковий розбір журналу без завантаження файлу в пам'ять;
- сувора валідація записів (ідентифікатор, hex-байт стану, скінченне
  число, ISO-8601 мітка часу);
- об'єктна модель сенсорів з інкапсуляцією (`@property`),
  перевантаженими `__str__`, `__repr__`, `__eq__`, `__hash__`;
- розшифрування апаратних прапорців побітовою арифметикою (`IntFlag`);
- фільтрація за вузлами, типами, діапазоном значень і часом;
- агрегація за унікальними вузлами за один прохід;
- відмовостійкий запис звіту (тимчасовий файл + атомарне перейменування);
- 47 модульних і наскрізних тестів (`unittest`).

## Швидкий старт

```bash
cd telemetry_tool
python3 -m telemetry_tool data/telemetry.log -o report.txt
python3 -m unittest discover -s tests -t . -v
```

Приклад звіту: [`docs/report_example.txt`](docs/report_example.txt).

## Формат журналу

```
NODE-ID;STATUS_HEX;VALUE;TIMESTAMP
TEMP-01;0x0F;23.54;2026-11-17T08:00:00+02:00
```

| Поле | Опис | Обмеження |
|------|------|-----------|
| `NODE-ID` | ідентифікатор вузла | `[A-Z]{2,8}-[0-9]{1,4}` |
| `STATUS_HEX` | регістр стану | `0x00`–`0xFF`, 2 hex-цифри |
| `VALUE` | виміряне значення | скінченне число з рухомою комою |
| `TIMESTAMP` | час вимірювання | ISO-8601, `T` або пробіл, `Z`/зсув |

Порожні рядки та рядки, що починаються з `#`, ігноруються.

### Прапорці стану

| Біт | Прапорець | Критичний |
|-----|-----------|-----------|
| 0x01 | `ONLINE` | – |
| 0x02 | `OVERHEAT` | так |
| 0x04 | `POWER_FAIL` | так |
| 0x08 | `SENSOR_FAULT` | так |
| 0x10 | `CALIBRATION` | – |
| 0x20 | `LOW_BATTERY` | – |
| 0x40 | `COMM_ERROR` | так |
| 0x80 | `MAINTENANCE` | – |

## Командний рядок

```
python -m telemetry_tool LOG [-o REPORT] [--node ID ...]
       [--sensor-type {flow,generic,pressure,temperature} ...]
       [--min-value X] [--max-value Y] [--since ISO] [--until ISO]
       [--critical-only] [--strict] [--quiet]
```

Типовий звіт зберігається поруч із журналом як `<журнал>.report.txt`.

Коди виходу: `0` — успіх, `2` — помилка доступу/розбору, `3` — помилка
запису звіту, `1` — непередбачена помилка.

## Структура проєкту

```
telemetry_tool/
├── telemetry_tool/
│   ├── __init__.py      # публічний API через __all__
│   ├── __main__.py      # захищена точка входу python -m
│   ├── exceptions.py    # ієрархія винятків
│   ├── models.py        # StatusFlag, Sensor і нащадки, фабрика
│   ├── parser.py        # регулярний вираз, валідація, генератори
│   ├── storage.py       # TelemetryLog, ReportWriter (RAII)
│   ├── analytics.py     # фільтрація, групування, агрегація
│   ├── report.py        # формування текстового звіту
│   └── cli.py           # argparse, try/except/else/finally
├── data/telemetry.log   # демонстраційний журнал (28 валідних + 6 битих)
├── docs/
│   ├── ZVIT.md          # Завдання 1 і 3 (проєктування та теорія)
│   └── report_example.txt
├── tests/               # unittest-набір
└── pyproject.toml       # метадані та конфігурація PEP 8 / ruff
```
